# sevtehexpert.ru

Сайт ООО «Севтехэксперт» — независимая строительная экспертиза и автоэкспертиза.

Статический сайт, хостинг Render (Static Site), домен sevtehexpert.ru.

- `index.html` — главная страница, стили и скрипт внутри
- форма заявки шлёт сообщение в Telegram: токен бота и chat_id — в начале блока «Заявки» в скрипте `index.html` (`TG_TOKEN`, `TG_CHAT`)
- `robots.txt`, `sitemap.xml` — для Яндекса и Google
